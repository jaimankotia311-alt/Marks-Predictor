# Marks-Predictor
A Machine Learning project that predicts a student's exam score based on the number of hours studied using Simple Linear Regression. The dataset contains 300 synthetically generated records created with NumPy for learning and experimentation. Built with Python, Scikit-learn, Joblib, and Streamlit.
